What do these columns mean?
ColumnTypeMeaning
Num integer CICY index, 1–7890.
\(h^{1,1}\) integer Hodge number.
\(h^{2,1}\) integer Hodge number.
Fav. bool Favorable presentation (projective product) exists.
K-fav. bool Kähler-favorable: Kähler and Mori cones descend from the ambient. Strictly stronger than Fav.; only K-favorable rows carry computed Coxeter data.
Product bool Direct product of lower-dimensional Calabi–Yaus.
Rank(\(W\)) integer Rank of the iso-flop Coxeter group; — when the model is not Kähler-favorable.
Kind string finite | affine | indefinite | trivial | sentinel. The first three are paper-conventional; trivial = K-favorable with no iso-flop walls; sentinel = not K-favorable.
Coxeter string Concise Coxeter-group label: Z2, I2(m) with m ∈ {2, 3, 4, P, H}, or — for higher rank — the canonical diagram-shape name (e.g. A1+B2).
ShapeKey* string Canonical diagram-shape id (used by the Diagram-shape facet above and in the Parquet artefact).

Sentinel conventions. Non-Kähler-favorable rows hold NULL in Rank(W), Kind = sentinel, Coxeter = NonKahlerPos. Empty CoxeterMat = {} denotes the trivial case (no iso-flop walls); a single reflection \(\mathbb{Z}_2\) is encoded as {{1}}. In I2(m) labels, P and H both denote \(m=\infty\) but distinguish parabolic vs hyperbolic representations of the same abstract group.

* Not shown in the table; available via the Diagram-shape facet and the Parquet artefact at /cicy-coxeter/cicy-coxeter.parquet.
