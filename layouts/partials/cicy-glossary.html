Glossary & conventions
Iso-flop row — Type 1a
A configuration-matrix row that yields an isomorphic flop via a projective-space swap whose flop map restricts to the identity on the ambient factor (see paper §3.2).
Iso-flop row — Type 1b
A configuration-matrix row yielding an iso-flop whose ambient action is non-trivial but still a linear automorphism; distinguished from Type 1a by the sign pattern of the induced Kähler reflection.
Iso-flop row — Type 2
A configuration-matrix row yielding an iso-flop that mixes ambient factors — the Kähler reflection is no longer block-diagonal.
Parabolic (P) vs hyperbolic (H)
Both labels denote a Coxeter-matrix entry mij = ∞, i.e. Qij = MiMj has infinite order. The distinction is which faithful representation realises the relation: P is parabolic (Gram matrix positive semi-definite) while H is hyperbolic (indefinite). See §4.1 of the paper.
Non-Kähler-favorable (NonKahlerPos)
The CICY admits no favorable Kähler presentation: its Kähler / Mori cones do not descend directly from the ambient product. No Coxeter data is computed; the corresponding fields in the database carry the NonKahlerPos sentinel.
